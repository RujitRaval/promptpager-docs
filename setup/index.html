Set up PromptPager

Install PromptPager on your Mac, let it configure your coding agents, then pair securely with PromptPager on iPhone. No separate bridge, Node.js, npm, Homebrew, or relay setup is required.

Download PromptPager 0.4.1 for Mac Release notes

Universal app for Apple silicon and Intel · Requires macOS 14 or later · Signed with Developer ID and notarized by Apple

1. Install PromptPager on your Mac

  1. Download and open the ZIP file above.
  2. Move PromptPager.app to your Applications folder.
  3. Open PromptPager from Applications. Its icon appears in the Mac menu bar.

PromptPager is signed and notarized. You should not need to bypass macOS security warnings. If macOS says the app cannot be verified, stop and contact support instead of overriding Gatekeeper.

2. Set up your Mac

  1. Open the PromptPager menu-bar menu and click Set Up PromptPager.
  2. Choose the folder where you normally run coding-agent sessions if prompted.
  3. Sign in to Claude Code or Codex if PromptPager reports that authentication is required.
  4. Keep the six-digit pairing code shown by PromptPager on screen.

The Mac app installs PromptPager's Claude hooks, enables Codex support, configures secure remote notifications, and manages its own private runtime. It starts automatically when you sign in to your Mac and stops when you quit PromptPager. PromptPager does not receive or store your Claude or Codex credentials.

3. Pair the iPhone app

  1. Connect the iPhone and Mac to the same trusted Wi-Fi network.
  2. Open PromptPager Settings.
  3. Select your discovered Mac. Its host and port are filled in automatically.
  4. Tap Connect, enter the six-digit code shown by PromptPager on the Mac, and tap Pair.

PromptPager on the Mac securely transfers the remote-notification configuration during pairing. Do not append another port number or enter a relay key manually.

4. Connect Apple Watch

Install the included PromptPager companion from the Watch app on iPhone, then open PromptPager on Apple Watch once. Questions from an active session can then appear on both devices.

5. Start working

Run Claude Code or Codex normally on your Mac. PromptPager shows active sessions and forwards genuine questions that need your response. Tool authorization in Claude Code's auto mode remains controlled by Claude's own classifier.

For contributors

The npm and Homebrew packages are compatibility tools for contributors and advanced development workflows. They are not part of customer setup. Customers should install PromptPager.app above and should never expose its local service directly to the public internet.
