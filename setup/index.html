Set up PromptPager

Run the bridge on your Mac, then pair it securely with PromptPager on iPhone.

1. Start the bridge

On your Mac, open Terminal and run:

npx @rujitraval/promptpager --host 0.0.0.0

The bridge prints a six-digit pairing code and starts a built-in demo session.

2. Pair the iPhone app

  1. Connect the iPhone and Mac to the same trusted Wi-Fi network.
  2. Open PromptPager Settings.
  3. Select the discovered bridge, or enter the Mac's local IP address and port 47900.
  4. Tap Connect, enter the six-digit code shown in Terminal, and tap Pair.

3. Connect Apple Watch

Install the included PromptPager companion from the Watch app on iPhone, then open PromptPager on Apple Watch once. Questions from an active session can then appear on both devices.

4. Keep it secure

Use PromptPager only on networks you trust. Pairing exchanges the temporary code for a device credential. Do not expose the bridge directly to the public internet. Closed-app remote notifications require a user-controlled authenticated HTTPS relay.
