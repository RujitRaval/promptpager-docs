PromptPager Support

For setup questions, connection problems, notification issues, or feedback, email rujit@aarolabs.ai.

Quick checks

  1. Open the PromptPager menu-bar menu and confirm the bridge is running. Use Repair Setup if it is not.
  2. Keep your iPhone and Mac on the same network for local discovery and pairing.
  3. Allow Local Network and Notifications when iOS requests them.
  4. Open the Apple Watch app once after installation so it can register and synchronize.

Connection help

If automatic discovery does not find your Mac, confirm both devices are on the same trusted Wi-Fi network and use Repair Setup from the Mac companion. As a fallback, enter the Mac's local IP address and port 47900 in PromptPager Settings. Use the six-digit pairing code shown by the companion.

Notification help

Notifications require permission on iPhone and Apple Watch. The Mac companion configures secure closed-app delivery during pairing; customers do not need to create or configure a relay account. If delivery stops, run Repair Setup, reconnect the iPhone, and open the Watch app once.

Download the Mac companion

Download the signed and notarized PromptPager 0.3.0 universal Mac app, or follow the complete setup guide.

When contacting support: include your iOS/watchOS versions, PromptPager version, bridge version, and a short description of what you expected and what happened. Never send pairing codes, relay keys, or APNs credentials.
